## 2. 公开接口

### 2.1 列表

```http
GET /api/school-materials
```

| 参数 | 必填 | 说明 |
|---|---:|---|
| `page` | 否 | 默认1，最小1 |
| `size` | 否 | 默认20，限制1—50 |
| `resourceCategory` | 否 | 精确筛选资料大类 |
| `subjectCategory` | 否 | 精确筛选科目/主题 |
| `resourceType` | 否 | 精确筛选资料类型 |
| `keyword` | 否 | 模糊搜索标题或稳定资源编号 |
| `year` | 否 | 同时匹配适用届别 `target_year` 或原始资料年份 `source_year` |

只返回 `status=1 AND is_deleted=0`。默认按 `sort_order ASC, id DESC` 稳定分页。

实际响应示例：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "records": [{
      "id": 1,
      "resourceCode": "z2026-997c2338c94343f3",
      "title": "2024交附自招数学真题-含答案",
      "resourceCategory": "自招配套资料",
      "subjectCategory": "数学",
      "resourceType": "真题及答案",
      "summary": "",
      "publishDate": "",
      "year": "2026",
      "coverUrl": null,
      "hasAttachment": true
    }],
    "total": 13,
    "page": 1,
    "size": 20
  }
}
```

    "resourceType": "真题及答案",
    "year": "2026",
    "summary": "",
    "content": "",
    "attachments": [{
      "id": 1,
      "name": "2024交附自招数学真题-含答案.pdf",

      "extension": "pdf",

不存在、已下架或已删除返回：

```json
{"code":404,"msg":"资料不存在或已下架","data":null}
```

### 2.3 文件下载

```http
GET /api/school-materials/{id}/download
```

- 无需登录；
- 直接从数据库 BLOB 返回真实文件；
- 响应包含正确的 `Content-Type`、`Content-Length`、UTF-8 文件名和 `X-Content-Type-Options: nosniff`；
- 文件不存在/下架/损坏返回 HTTP 404；
- PDF、DOC、DOCX、XLS、XLSX 均可按数据库 MIME 返回。

## 4. 下载 URL 与云端配置

本地详情会返回当前请求主机，例如：

```text
http://127.0.0.1:18082/api/school-materials/1/download
```

云托管部署时必须设置环境变量：

```text
MATERIAL_PUBLIC_BASE_URL=https://实际可公网访问的云托管API域名
```

未设置时，后端会根据请求的 `Host`、`X-Forwarded-Host`、`X-Forwarded-Proto` 生成地址；已实测转发头为 HTTPS 时会生成 HTTPS 下载 URL。建议生产显式设置变量，避免代理层 Host 不一致。

因为文件由后端 HTTPS 域名返回，小程序公众平台需要把该 API 域名加入 `downloadFile` 合法域名；不再要求 OSS 域名。本地调试 HTTP 仅用于开发者工具，真机和生产必须使用 HTTPS。

## 5. 前端调用

首页继续跳转资料列表，列表请求参数改用本文件中的 `resourceCategory`、`subjectCategory`、`resourceType`。详情中的 `attachments[0].url` 可直接交给：

```js
wx.downloadFile({
  url: attachment.url,
  success: ({ statusCode, tempFilePath }) => {
    if (statusCode !== 200) return
    wx.openDocument({
      filePath: tempFilePath,
      fileType: attachment.extension,
      showMenu: true
    })
  }
})
```

## 8. 与需求文档的差异

- 当前没有附件关联表：一行资源就是一份文件，因此详情固定返回一个附件；`file_content NOT NULL` 保证有效记录不是空附件。
- 文件尚未获授权外传 OSS，所以下载由后端从数据库 BLOB 流式返回；这仍是可公开访问的持久 HTTPS API，但会消耗后端实例带宽和数据库连接。
- 当前实现一次将文件读入内存，最大文件约7MB，现有13份资料可接受。资源规模明显扩大后，应经授权迁往对象存储并切换为持久对象 URL。
- 正式前端源码不在本机，本次只交付后端与可直接执行的前端契约，没有修改旧前端副本。
