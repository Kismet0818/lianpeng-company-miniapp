> 完成日期：2026-09-15  
> 本地基础地址：`http://localhost:8080`（验收使用 `http://127.0.0.1:18082`）  
> 状态：本地后端完成；幼儿园表及数据已迁移云数据库，后端代码尚未部署云托管。

## 1. 最终接口

| 功能 | 方法与路径 | 鉴权 |
|---|---|---|
| 幼儿园列表 | `GET /api/kindergartens` | 公开 |
| 幼儿园详情 | `GET /api/kindergartens/{id}` | 公开 |
| 学校比对搜索 | `GET /api/school-compare/search?level=kindergarten&keyword=...` | 公开 |
| 学校比对详情 | `POST /api/school-compare/details` | 公开 |

新资源已加入 JWT 公开白名单和公开查询限流；详情路径按公开详情接口限流。线上使用前必须重新构建并部署后端。

## 2. 列表参数

```http
GET /api/kindergartens?page=1&size=20&district=徐汇区&keyword=幼儿园&schoolType=民办
```

| 参数 | 默认/限制 | 行为 |
|---|---|---|
| `page` | 默认1；小于1归一为1；网关安全上限200 | 页码 |
| `size` | 默认20；控制器归一到1～500 | 每页数量 |
| `district` | 可选 | 精确匹配数据库区名，须URL编码 |
| `keyword` | 可选 | 对全名、简称做参数化包含匹配 |
| `name` | 可选兼容别名 | 仅当 `keyword` 为空时生效 |
| `schoolType` | 可选；`公办`/`民办` | 精确匹配办园性质 |

只返回 `is_active=1` 的记录。默认按 `district + name + id` 升序稳定排序。

## 3. 详情

```http
GET /api/kindergartens/10000001
```

成功时 `data` 是单个对象，字段与列表项完全相同。不存在、非正数或已停用记录返回真实HTTP 404：

```json
{"code":404,"msg":"幼儿园不存在","data":null}
```

## 4. 字段映射与空值

| 数据库字段 | 接口字段 | 说明 |
|---|---|---|
| `id` | `id` | 幼儿园表主键 |
| `name` | `name` | 园所全名 |
| `short_name` | `shortName` | 可空 |
| `background_image_url` | `backgroundImageUrl` | 完整HTTPS图片URL；可空 |
| `district` | `district` | 上海行政区 |
| `tuition_min/max` | `tuitionMin/Max` | 万元/年；未知为null |
| `school_type` | `schoolType` | 当前真实枚举为公办/民办 |
| `kindergarten_level` | `kindergartenLevel` | 一级园、二级园等；可空 |
| `care_type` | `careType` | 日托、全日托、有托班等来源文本；可空 |
| `age_range` | `ageRange` | 来源年龄范围文本；可空 |
| `address` | `address` | 可空 |
| `phone` | `phone` | 可空 |
| `description` | `description` | 可空，不返回伪造简介 |
| `official_website` | `officialWebsite` | 可空 |
| `schedule` | `schedule` | 可空 |
| `teaching_features` | `teachingFeatures` | 可空 |
| `campus_area` | `campusArea` | 平方米；可空 |
| 代码固定值 | `schoolSource` | 始终 `kindergarten` |
| 代码固定值 | `schoolLevel` | 始终 `幼儿园` |

采集内部字段 `source_school_id` 是19位BIGINT，不对前端暴露，避免JavaScript整数精度问题；`school_code`、启停状态和审计时间也不属于页面契约。

## 5. 学校身份与跨模块接入

幼儿园的唯一业务身份必须使用：

```text
schoolSource=kindergarten + schoolId=id
```

不得只保存数字ID，也不得使用采集来源ID。缓存键建议为 `kindergarten:10000001`。

后端现已补齐以下分流：收藏、五级评价、祝福墙、浏览行为、最近浏览、用户反馈和学校比对。前端对应请求均需原样传 `schoolSource="kindergarten"`。幼儿园比对键为 `domestic:kindergarten:{id}`，只能与幼儿园同学段对比，最多6所。

前端需要：学校库学段增加“幼儿园”；列表改调本接口；新增或复用详情页；跳转、收藏、评价、祝福、埋点、最近浏览缓存和比对列表全程保留来源与ID。图片为空时使用本地占位图，简介/收费等为null时隐藏对应行，不能显示“0元”或虚构文案。

## 6. 错误处理

| 情况 | 建议 |
|---|---|
| 404 幼儿园不存在 | 提示资料已下线并返回列表 |
| 401 未授权 | 列表/详情不应出现；登录功能按现有流程重登 |
| 403 | 提示无权限，不循环重试 |
| 429 | 读取 `Retry-After`，延迟后重试 |
| 500/网络错误 | 展示重试按钮并保留当前筛选 |

## 9. 已知限制与口径

- 来源列表接口返回2504条幼儿园原始记录；严格按 `cityName=上海市` 和上海16个行政区筛得2337条，再排除国际学校27条及性质缺失10条，最终接入2300条公办/民办园。接口参数本身不能可靠限定城市，抓取端与导入端均进行了独立校验。
- 这2300条是“上哪学”公开列表接口当前收录并符合上述口径的数据，不应宣传为上海市教育主管部门发布的官方完整名录；仅凭来源接口无法进一步证明每所园的监管资质。
- 来源详情接口需要动态会话签名，HAR中的openid单独无法复用；因此未绕过访问限制。当前简介、电话、学费等保持null，后续获得合规公开来源后可幂等补充。
- 图片为来源平台公开HTTPS地址，没有签名有效期；若后续迁移OSS，需先下载校验、再批量更新URL。
- 云数据库已迁移同结构数据：2302条物理记录、2300条有效记录；迁移后唯一性、性质分布、16区分布及原有用户数均已核验。后端代码尚未部署云托管。
- 本地导入前56条快照保存在 `kindergarten_backup_before_full_import_20260915`；云端迁移时目标表原本不存在，未覆盖旧幼儿园表。
