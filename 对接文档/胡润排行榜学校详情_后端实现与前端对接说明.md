# 胡润排行榜学校详情：后端实现与前端对接说明

> 完成日期：2026-09-16  
> 当前状态：本地代码、本地数据库迁移和真实 HTTP 验收完成；未迁移云数据库、未部署云托管、未修改正式前端。

## 1. 实际接口

### 1.1 胡润榜单

```http
GET /api/rankings/hurun?year=2025&page=1&size=100&city=上海市
```

参数：

| 参数 | 必填 | 规则 |
|---|---:|---|
| `year` | 否 | 默认2025，限制2000—2100 |
| `page` | 否 | 默认1，最小1 |
| `size` | 否 | 默认100，限制1—100 |
| `city` | 否 | 城市精确筛选，`上海` 与 `上海市` 等价 |

实际响应：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "ranking": "hurun",
    "year": "2025",
    "title": "2025胡润百学·中国国际化学校100强",
    "subtitle": "Hurun Education Top International Schools in China 2025",
    "records": [{
      "rank": 1,
      "index": 100.00,
      "name": "上海民办包玉刚实验学校",
      "city": "上海",
      "schoolId": 17,
      "schoolSource": "international"
    }],
    "total": 15,
    "page": 1,
    "size": 100
  }
}
```

榜单只返回 `status=1 AND is_deleted=0` 的记录，按 `rank_position ASC, id ASC` 稳定分页。学校不存在或已下架时，榜单记录仍保留，但 `schoolId=null`，前端不得跳转；`schoolSource` 仍固定为 `international`。

### 1.2 体制外学校详情

复用：

```http
GET /api/schools/{schoolId}
```

该接口现已明确返回：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "id": 17,
    "schoolSource": "international",
    "name": "上海民办包玉刚实验学校",
    "city": "上海",
    "district": "长宁区",
    "curriculum": "IGCSE课程，IBDP课程，双语课程",
    "grades": "小学,初中",
    "schoolType": "民办九年一贯制",
    "logoUrl": "https://...",
    "tuitionMin": null,
    "tuitionMax": null,
    "description": "...",
    "boardingInfo": "..."
  }
}
```

具体字段继续沿用现有体制外 `school` 实体，包括课程、学费、优势标签、学段、介绍、升学、寄宿、班额、师生比、Logo、授课方式、创办时间、学生数、占地、性质、地址、官网、作息和教学特色等。数据库没有的字段返回 `null`，不伪造。

学校不存在、已下架或 ID 非法：

```json
{"code":404,"msg":"学校不存在或已下架","data":null}
```

## 2. 数据库映射

榜单表：`school_ranking_entry`。  
学校表：`school`。

关联方式是稳定外键：

```text
school_ranking_entry.school_id → school.id
```

不使用学校名称模糊匹配。榜单展示名保存在 `display_name`，即使学校更名，关联仍由 `school_id` 保持稳定。

本次本地迁移为榜单表增加：

- `school_source`：固定 `international`，带检查约束；
- `status`：1启用、0停用；
- `is_deleted`：软删除；
- 公开查询复合索引。

迁移脚本：`tools/upgrade_school_ranking_entry_for_api.sql`。该脚本是一次性迁移，执行前应先检查云库字段，避免重复 `ALTER TABLE`。

当前本地数据：15条榜单记录、15个非空学校ID、15个唯一体制外学校、15所均启用。

## 3. 端到端调用

先取榜单：

```http
GET /api/rankings/hurun?year=2025&city=上海市
```

第1名返回：

```json
{
  "rank": 1,
  "name": "上海民办包玉刚实验学校",
  "city": "上海",
  "schoolId": 17,
  "schoolSource": "international"
}
```

前端跳转：

```text
/pages/school-detail/school-detail?id=17&schoolSource=international
```

详情请求：

```http
GET /api/schools/17
```

真实验收中返回学校 ID 17、`schoolSource=international`，并存在学校性质、学段、课程体系、Logo 和介绍。

## 4. 前端规则

1. 排行榜页面不再维护静态学校 ID，展示数据直接取榜单接口。
2. `schoolId != null` 时才允许点击。
3. 跳转必须固定携带 `schoolSource=international`。
4. `schoolId=null` 时显示“学校详情暂不可用”，不得按名称搜索替代。
5. 接口业务码404时，详情页显示“学校不存在或已下架”。

## 5. 权限与错误

- 榜单和学校详情均为公开接口，无需 JWT。
- 无对应年份或城市时返回业务码200、空数组和 `total=0`。
- 学校无效或下架时，详情返回业务码404。
- 榜单映射学校失效时返回 `schoolId=null`，不会关联到同名学校。

## 8. 与需求文档的差异

- 数据库城市快照采用 `上海/北京/深圳/苏州/佛山/广州`，接口接受带“市”的筛选值但返回数据库原始快照。
- 榜单接口额外返回 `index`，对应胡润榜单指数。
- 现有体制外学校表没有独立 `shortName`、`backgroundImageUrl`、结构化 `contact` 或嵌套 `admissionContent` 字段；继续沿用现有详情接口和现有图片/招生子接口，不伪造字段。
- 正式前端源码不在本机，本次未修改旧前端副本。
