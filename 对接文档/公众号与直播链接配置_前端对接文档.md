# 公众号与直播链接配置对接

## 目标

老板在管理后台只需粘贴 HTTPS 链接并保存。小程序每次进入页面或下拉刷新时读取公开接口，无需重新发版即可显示最新配置。

## 小程序公开接口

```http
GET /api/content-links
GET /api/content-links?type=OFFICIAL_ACCOUNT
GET /api/content-links?type=LIVE
```

无需 Token。只返回 `status=1` 的记录。

```json
{
  "code": 200,
  "msg": "成功",
  "data": [
    {
      "id": 1,
      "contentType": "OFFICIAL_ACCOUNT",
      "title": "最新公众号内容",
      "linkUrl": "https://mp.weixin.qq.com/...",
      "status": 1,
      "updateTime": "2026-09-16T16:30:00"
    }
  ]
}
```

## 前端处理

- 页面进入和下拉刷新时重新请求，不要把链接写死在小程序。
- `OFFICIAL_ACCOUNT` 用于公众号内容入口，`LIVE` 用于直播入口。
- 接口未返回某类型时，对应入口应隐藏。
- 微信是否允许直接打开目标链接，仍受小程序业务域名和视频号能力限制。拿到真实链接后再确认最终跳转方式。

## 管理接口

```http
GET /api/admin/content-links
PUT /api/admin/content-links/OFFICIAL_ACCOUNT
PUT /api/admin/content-links/LIVE
PATCH /api/admin/content-links/{type}/status?active=0或1
X-Admin-Key: <管理密钥>
```

```json
{
  "title": "显示标题，可不填",
  "linkUrl": "https://...",
  "status": 1
}
```

当前每种类型保留一条最新配置，重复保存会更新原记录。
