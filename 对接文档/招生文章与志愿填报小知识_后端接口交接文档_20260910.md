## 2. 接口清单

### 2.1 文章列表

```http
GET /api/admission-content/articles
```

请求参数：

| 参数 | 必填 | 默认值 | 说明 |
|---|---:|---:|---|
| `category` | 是 | 无 | 只支持 `详细文章`、`志愿填报小知识` |
| `year` | 否 | 无 | 仅 `详细文章` 使用；知识类会忽略该参数 |
| `page` | 否 | 1 | 小于 1 时按 1 处理 |
| `size` | 否 | 20 | 范围 1～100 |

前端当前使用：

```text
GET /api/admission-content/articles?category=详细文章&year=2026
GET /api/admission-content/articles?category=志愿填报小知识
```

真实响应摘要：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "records": [
      {
        "id": 19,
        "category": "志愿填报小知识",
        "title": "中考有哪些科目，分数如何分配",
        "year": null,
        "contentFormat": "text_with_images",
        "coverImageUrl": "https://lianpeng.oss-cn-shanghai.aliyuncs.com/admission-content/missing-subject-score/01.png",
        "imageCount": 1,
        "sortOrder": 2
      }
    ],
    "total": 11,
    "size": 20,
    "current": 1,
    "pages": 1
  }
}
```

列表只返回摘要，不返回 `contentText`。按 `sortOrder ASC, id ASC` 稳定排序。

### 2.2 文章详情

```http
GET /api/admission-content/articles/{id}
```

真实响应示例（`id=19`）：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "id": 19,
    "category": "志愿填报小知识",
    "title": "中考有哪些科目，分数如何分配",
    "year": null,
    "contentFormat": "text_with_images",
    "contentText": "上海市初中学业水平考试科目和分值设置……",
    "imageUrls": [
      "https://lianpeng.oss-cn-shanghai.aliyuncs.com/admission-content/missing-subject-score/01.png"
    ],
    "imageCount": 1
  }
}
```

无图文章固定返回 `imageUrls: []`，不会返回 `null`。`imageCount` 以实际 `imageUrls.length` 为准。

文章不存在：

```json
{
  "code": 404,
  "msg": "文章不存在",
  "data": null
}
```

项目统一响应目前使用 HTTP 200 承载业务码，因此前端必须判断 JSON 的 `code`，不能只判断 HTTP 状态。

## 3. 前端展示约定

- `contentFormat=text`：展示 `contentText`，不渲染图片区域。
- `contentFormat=text_with_images`：展示 `contentText`，并按 `imageUrls` 数组顺序渲染图片。
- 列表封面使用 `coverImageUrl`；为 `null` 时使用前端默认封面或不展示封面。
- 详情页不要使用数据库字段名 `oss_image_urls`，接口字段固定为 `imageUrls`。
- 接口不会暴露 `source_url`、`image_urls`、`local_image_files`、`capture_note`。

## 4. 业务规则

- `详细文章` 当前仅有 2026 年 1 篇；传 `year=2026` 返回该文章。
- 年份由请求参数和数据库数据共同决定，后端未写死 2026，后续可直接新增年度数据。
- `志愿填报小知识` 当前 11 篇，`year` 均为 `null`，不按年份过滤。
- 接口只返回 `capture_status=text_complete` 的完整正文。
- 非法分类返回 `code=400`、`msg=文章分类不正确`。
- 无查询结果返回成功的空分页，不伪造文章数据。
