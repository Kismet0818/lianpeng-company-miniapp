# 资料下载记录功能：前端对接交接文档

> 日期：2026-09-16  
> 适用项目：联朋升学微信小程序  
> 对接范围：择校资料列表、详情及附件下载；升学路径图片与附件保存  
> 后端状态：代码、本地数据库表、正式云数据库表均已完成；后端新版本仍需部署后生效。

## 1. 功能目标

用户下载任何一份择校资料后，管理后台需要看到：

- 哪个用户下载；
- 下载了哪份资料；
- 下载发生的时间。

后端会在成功读取文件、准备返回下载响应时写入一条下载记录。记录保存资料标题、业务编号和文件名快照，因此资料以后改名也不会改变历史记录。

## 2. 前端必须修改的地方

资料列表和详情接口仍然公开，不要求登录：

```text
GET /api/school-materials
GET /api/school-materials/{id}
```

资料下载接口已经改为必须登录：

```text
GET /api/school-materials/{id}/download
Authorization: Bearer <用户登录 Token>
```

前端不能再把详情接口返回的附件 URL 直接交给一个不带请求头的下载方法。调用 `wx.downloadFile` 时必须显式携带当前用户 Token。

## 3. 推荐下载实现

以下代码中的 Token 读取方式需要替换成正式前端项目现有的统一登录状态读取方法，不要另外维护第二份 Token。

```javascript
function downloadMaterial(attachment) {
  const token = wx.getStorageSync('token')

  if (!token) {
    wx.showToast({ title: '请先登录后下载', icon: 'none' })
    // 按正式项目现有流程进入登录或手机号授权页面。
    return
  }

  wx.showLoading({ title: '正在下载' })

  wx.downloadFile({
    url: attachment.url,
    header: {
      Authorization: `Bearer ${token}`
    },
    success(res) {
      if (res.statusCode === 200) {
        wx.openDocument({
          filePath: res.tempFilePath,
          showMenu: true,
          fail() {
            wx.showToast({ title: '文件打开失败', icon: 'none' })
          }
        })
        return
      }

      if (res.statusCode === 401 || res.statusCode === 403) {
        wx.removeStorageSync('token')
        wx.showToast({ title: '登录已失效，请重新登录', icon: 'none' })
        return
      }

      if (res.statusCode === 404) {
        wx.showToast({ title: '资料不存在或已下架', icon: 'none' })
        return
      }

      if (res.statusCode === 429) {
        wx.showToast({ title: '操作频繁，请稍后再试', icon: 'none' })
        return
      }

      wx.showToast({ title: `下载失败（${res.statusCode}）`, icon: 'none' })
    },
    fail() {
      wx.showToast({ title: '网络异常，下载失败', icon: 'none' })
    },
    complete() {
      wx.hideLoading()
    }
  })
}
```

## 4. 详情接口中的附件结构

资料详情接口：

```text
GET /api/school-materials/{id}
```

返回结构仍使用项目统一格式：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": 1,
    "resourceCode": "稳定业务编号",
    "title": "资料标题",
    "attachments": [
      {
        "id": 1,
        "name": "文件名.pdf",
        "url": "https://正式域名/api/school-materials/1/download",
        "extension": "pdf",
        "mimeType": "application/pdf",
        "size": 123456,
        "sort": 1
      }
    ]
  }
}
```

前端继续使用 `attachments[n].url` 作为下载地址，但必须通过携带 `Authorization` 请求头的 `wx.downloadFile` 发起请求。

## 5. 登录与兼容性要求

1. 用户点击下载时如果尚未登录，应先引导完成正式登录流程。
2. Token 失效后不要不断重试下载，应清理失效 Token 并引导重新登录。
3. 不要把 Token 拼接到 URL 查询参数中，避免出现在日志、分享链接或截图里。
4. 不要把下载链接改成普通 `<navigator>`、复制链接或不带 Header 的直接打开方式。
5. 列表浏览和资料详情浏览不强制登录，只有实际下载需要登录。
6. 前端不需要另行调用“上报下载记录”接口；下载记录由后端在返回文件时自动生成，避免客户端伪造或漏报。

## 6. HTTP 状态处理

| HTTP 状态 | 含义 | 前端处理 |
|---|---|---|
| `200` | 下载成功，后端已写入记录 | 使用 `wx.openDocument` 打开 |
| `401` | 未登录、Token 无效或已过期 | 清理失效登录态并重新登录 |
| `403` | 用户账号已停用 | 提示账号不可用，不继续重试 |
| `404` | 资料不存在、已下架或文件异常 | 提示资料暂不可用并刷新列表 |
| `429` | 请求过于频繁 | 提示稍后再试 |
| `5xx` | 后端或数据库异常 | 提示服务异常，保留日志便于排查 |

下载接口返回的是文件二进制，不是 `{code,msg,data}` JSON。前端应以 `wx.downloadFile` 的 `statusCode` 判断结果。

## 7. 管理后台效果

更新后的管理后台新增：

```text
📥 资料下载记录
```

后台可查看：

- 用户编号；
- 用户昵称；
- 已绑定手机号；
- 资料标题；
- 资料业务编号；
- 文件名；
- 下载时间。

支持按用户编号、昵称、手机号、资料标题、资料编号或文件名搜索。前端不需要对接管理接口。

## 8. 联调验收清单

- [ ] 未登录点击下载时，前端提示登录，不发起匿名下载。
- [ ] 已登录用户可以正常下载 PDF。
- [ ] 已登录用户可以正常下载 DOCX 等非 PDF 文件。
- [ ] 下载请求 Header 中存在 `Authorization: Bearer ...`。
- [ ] 下载成功后文件名、MIME 类型和文件内容正确。
- [ ] 同一用户连续下载两次，后台出现两条记录。
- [ ] 两个不同用户下载同一资料，后台能正确区分用户。
- [ ] Token 失效后返回 401，前端进入重新登录流程。
- [ ] 已下架或不存在的资料返回 404，不产生下载记录。
- [ ] 管理后台按手机号和资料名称搜索均能命中。

## 11. 升学路径图片/附件保存上报（必须接入）

微信原生“长按保存图片”没有可供业务代码使用的保存成功回调，所以页面必须提供明确的“保存资料”按钮。先调用 `wx.saveImageToPhotosAlbum`，只有微信返回保存成功后才上报：

```http
POST /api/material-downloads/report
Authorization: Bearer <token>
Content-Type: application/json
```

结构化附件优先使用详情接口返回的 `attachmentId`：

```json
{
  "sourceType": "GUIDE",
  "sourceId": 123,
  "attachmentId": 456
}
```

正文内图片没有附件 ID 时，传文章详情中原样返回的图片地址：

```json
{
  "sourceType": "GUIDE",
  "sourceId": 123,
  "fileUrl": "https://lianpeng.oss-cn-shanghai.aliyuncs.com/guide/example.jpg",
  "fileName": "example.jpg"
}
```

后端会校验附件或图片确实属于该文章，用户身份只从 Token 获取。用户取消、保存失败时不得上报，同一次点击只能上报一次。

择校资料仍使用 `/api/school-materials/{id}/download` 并携带 Token，由后端自动记录，不要再调用上报接口，否则会重复计数。
