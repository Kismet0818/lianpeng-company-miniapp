# 联朋升学老板管理后台｜新版使用说明

## 启动

1. 解压整个文件夹，不要只拖出 `admin.html`。
2. 双击 `双击我启动后台.bat`。
3. 浏览器会自动打开 `http://localhost:3000`；如果没有自动打开，请手动访问该地址。
4. 输入管理密钥并点击“保存”。
5. 使用完毕后关闭黑色 PowerShell 窗口即可停止后台页面。

本启动包不需要安装 Node.js、Java、MySQL 或微信开发者工具。它只是管理页面启动器，数据仍通过线上云托管后端读写。

## 视频号短视频

点击顶部“视频号/直播”，在“视频号短视频”区域录入：

- `feed_id`：视频号短视频的 feed ID，必填；
- 视频标题，必填；
- 封面地址，可选；
- “在小程序展示”勾选后才会公开展示。

可新增、编辑、删除和隐藏短视频。短视频不是公众号文章，不需要填写公众号文章链接。

## 直播预约

直播预约与短视频分开管理。录入直播时间、视频号原始 ID、视频号名称和头像后，小程序会根据“视频号原始 ID + 直播时间”匹配微信视频号真实直播预告。

这里不需要填写直播链接。必须先在视频号发布真实直播预告，小程序才有可能完成预约。

## 常见问题

- 页面提示“服务器内部错误”：通常是云托管尚未部署包含视频号短视频或直播管理接口的新后端版本。
- 页面打不开：确认黑色窗口没有关闭，并访问 `http://localhost:3000`。
- 提示 3000 端口被占用：关闭旧的后台启动窗口后重新双击启动。
- 视频保存失败：检查 `feed_id` 和标题是否填写，确认管理密钥正确。
- 直播无法预约：检查视频号原始 ID、直播时间是否与微信视频号预告一致，并确认预告已开放预约。

## 后端接口依赖

- `GET /api/channels-videos`：小程序获取启用的短视频；
- `GET /api/admin/channels-videos`：后台读取短视频；
- `POST /api/admin/channels-videos`：新增短视频；
- `PUT /api/admin/channels-videos/{id}`：编辑短视频；
- `DELETE /api/admin/channels-videos/{id}`：删除短视频；
- `GET /api/admin/live-sessions` 及对应新增、编辑、删除接口：直播预约场次管理。

如果线上提示接口不存在，需要先部署新版后端，再使用本启动包。
