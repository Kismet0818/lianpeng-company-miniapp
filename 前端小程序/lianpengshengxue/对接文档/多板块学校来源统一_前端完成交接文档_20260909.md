## 三、修复前错误数据流 与 修复后正确数据流

### 修复前（错误）

```text
升学工具 → 一般高中列表（数据本身无来源标记）
→ 详情页 startSchoolView(this, 'score', id)
→ 上报 { schoolSource: 'score', schoolId: 304/317/346/368 }（实际属于 general_high_school）
→ 串校 / 浏览记录丢失 / 表情写错学校 / 祝福范围错误
```

### 修复后（正确）

```text
各板块列表映射时就标记真实 schoolSource（international / score / general / junior）
→ 点击学校跳转时 schoolSource + schoolId 一起传入详情页
→ 详情页 onLoad 校验并保存进 data.schoolSource
→ 浏览上报 startSchoolView、表情 GET/POST、祝福列表/发布 全部复用同一 data.schoolSource
```
