# 一般高中接口前端交接文档

## 一、处理结果

后端已补齐一般高中只读查询接口，并将以下路径加入 JWT 公开白名单：

```text
/api/general-high-schools/**
```

学校列表和详情无需登录、无需携带 Token。新增、修改、删除等管理接口没有对外开放。

本地后端已经编译并实际请求验证成功。线上环境需要部署本次后端代码并重启服务后，线上接口才会生效。

## 二、一般高中列表接口

```http
GET /api/general-high-schools
```

查询参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `page` | 否 | 页码，默认 `1` |
| `size` | 否 | 每页数量，默认 `20`，最大 `500` |
| `district` | 否 | 所属区，传值时精确匹配，例如 `崇明区` |

页面获取某区全部一般高中时建议调用：

```http
GET /api/general-high-schools?page=1&size=500&district=崇明区
```

成功响应示例：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "records": [
      {
        "id": 294,
        "name": "上海市崇明区横沙中学",
        "shortName": "横沙中学",
        "backgroundImageUrl": "https://example.com/school.jpeg",
        "district": "崇明区",
        "tuitionMin": null,
        "tuitionMax": null,
        "boardingInfo": null,
        "schoolType": "公办",
        "address": "上海市崇明区横沙乡民东路1503号",
        "description": "学校简介",
        "createdTime": "2026-09-03T10:12:06",
        "updatedTime": "2026-09-04T10:05:37"
      }
    ],
    "total": 3,
    "size": 500,
    "current": 1,
    "pages": 1
  }
}
```

前端必须从 `data.records` 读取学校数组，不能直接把 `data` 当成数组。

## 三、一般高中详情接口

```http
GET /api/general-high-schools/{id}
```

例如：

```http
GET /api/general-high-schools/294
```

成功响应：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "id": 294,
    "name": "上海市崇明区横沙中学",
    "shortName": "横沙中学",
    "backgroundImageUrl": "https://example.com/school.jpeg",
    "district": "崇明区",
    "tuitionMin": null,
    "tuitionMax": null,
    "boardingInfo": null,
    "schoolType": "公办",
    "address": "上海市崇明区横沙乡民东路1503号",
    "description": "学校简介"
  }
}
```

学校不存在时返回业务错误：

```json
{
  "code": 400,
  "msg": "一般高中不存在",
  "data": null
}
```

## 四、字段说明

| 字段 | 说明 |
|---|---|
| `id` | `general_high_school.id`，只能用于一般高中接口 |
| `name` | 学校全名 |
| `shortName` | 学校简称，可能为空 |
| `backgroundImageUrl` | 校园背景图，可能为空 |
| `district` | 所属区 |
| `tuitionMin` | 最低学费，可能为空 |
| `tuitionMax` | 最高学费，可能为空 |
| `boardingInfo` | 住宿信息，可能为空 |
| `schoolType` | 公办/民办 |
| `address` | 地址，可能为空 |
| `description` | 简介，可能为空 |

一般高中使用独立表和独立 ID。不要把 `general_high_school.id` 与市重点、区重点或初中表的 ID 混用。

## 五、前端加载与容错要求

市重点、区重点、一般高中可以并行请求，但不能让一个分类失败导致全部分类清空。

推荐使用 `Promise.allSettled`：

```js
const results = await Promise.allSettled([
  loadCityKeySchools(),
  loadDistrictKeySchools(),
  loadGeneralHighSchools()
])

const cityKeySchools = results[0].status === 'fulfilled'
  ? results[0].value
  : []

const districtKeySchools = results[1].status === 'fulfilled'
  ? results[1].value
  : []

const generalHighSchools = results[2].status === 'fulfilled'
  ? results[2].value
  : []
```

如果继续使用 `Promise.all`，每个请求必须在内部单独捕获错误并返回空数组。

请求层还应检查业务状态码：HTTP `200` 不代表业务一定成功，只有响应中的 `code === 200` 才算成功。

一般高中列表解析示例：

```js
async function loadGeneralHighSchools(district) {
  const result = await request(
    `/api/general-high-schools?page=1&size=500&district=${encodeURIComponent(district)}`,
    'GET'
  )

  return Array.isArray(result?.records) ? result.records : []
}
```

如果项目的统一 `request` 方法返回完整响应而不是 `data`，则改为读取：

```js
return Array.isArray(result?.data?.records)
  ? result.data.records
  : []
```

## 六、联调验收

后端部署重启后，请依次验证：

1. 不登录、不携带 Token 请求一般高中列表，业务状态应为 `200`；
2. 选择崇明区，一般高中应返回 3 条；
3. 点击学校后能使用该记录的 `id` 加载详情；
4. 一般高中接口故障时，市重点和区重点仍能正常显示；
5. 地区切换时清空上一地区旧数据，避免列表串区；
6. `backgroundImageUrl`、`description` 等空字段应有前端占位处理。
