## 二、修改文件

### 新增 `utils/activity.js`

提供统一方法：

- `startSchoolView(page, schoolSource, schoolId)`：进入详情页时开始计时
- `finishSchoolView(page)`：离开详情页时计算停留时长并上报

实现规则：

- 停留不足 3 秒不请求接口
- 没有本地 token 时不请求，并输出警告日志
- 请求成功后才设置 `sent=true`
- `sending` 防止 `onHide` 和 `onUnload` 重复上报
- 上报失败不会静默吞掉，会输出 `console.error`

### `pages/school-detail/school-detail.js`

在 `onLoad` 中调用：

```js
startSchoolView(this, 'international', options && options.id)
```

增加：

```js
onHide() { finishSchoolView(this) },
onUnload() { finishSchoolView(this) },
```

### `pages/score-school-detail/score-school-detail.js`

在 `onLoad` 中调用：

```js
startSchoolView(this, 'score', options && options.id)
```

增加同样的 `onHide/onUnload` 上报逻辑。

## 三、后端接口请求

前端调用：

```http
POST /api/user/activity
Authorization: Bearer <token>
Content-Type: application/json
```

请求体：

```json
{
  "schoolSource": "international",
  "schoolId": 17,
  "durationSeconds": 8
}
```

分数查询学校示例：

```json
{
  "schoolSource": "score",
  "schoolId": 101,
  "durationSeconds": 12
}
```

`schoolId` 传正整数，来源必须与后端数据表匹配；`durationSeconds` 为前端按秒取整后的停留时长。

## 四、前端日志

```

```

```text

```

不足 3 秒时前端直接不发送请求。

## 六、建议联调流程

同一用户依次访问：

1. 国际学校 A，停留 5～10 秒后返回。
2. 分数查询学校 B，停留 5～10 秒后返回。
3. 在后端日志或管理后台核对两条行为记录的学校来源、学校 ID 和停留秒数。
4. 再测试停留 1～2 秒，确认不会新增记录。
