# 首页“择校资料”实际资源库改造对接文档

## 1. 当前问题

前端目前调用 `/api/school-materials`，返回的是演示数据，例如“2026年上海中考到区分数线”。但实际资料存放在 `zhongkao_resource_file` 表中，字段包括：

- `id`
- `resource_code`
- `title`
- `resource_category`
- `subject_category`
- `resource_type`

因此当前页面显示内容与后台实际资料库不一致。请后端 Codex 以 `zhongkao_resource_file` 为真实数据源改造公开接口；不要继续返回演示资料或另建一套孤立的 demo 数据。

## 2. 公开接口要求

### 2.1 资料列表

```http
GET /api/school-materials?page=1&size=20
```

接口路径可以保持不变，以免前端重复改路由，但数据必须来自 `zhongkao_resource_file` 及其附件关联表。

支持参数：

| 参数 | 说明 |
|---|---|
| page | 页码，默认 1 |
| size | 每页数量，限制 1—50 |
| resourceCategory | 资料大类，对应 `resource_category` |
| subjectCategory | 科目/主题，对应 `subject_category` |
| resourceType | 资料类型，对应 `resource_type` |
| keyword | 按 `title`、`resource_code` 模糊搜索 |
| year | 按资料年份筛选，如 2026 |

成功响应统一为：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "records": [
      {
        "id": 1,
        "resourceCode": "z2026-997c2338c9434",
        "title": "2024交附自招数学真题-含答案",
        "resourceCategory": "自招配套资料",
        "subjectCategory": "数学",
        "resourceType": "真题及答案",
        "summary": "",
        "publishDate": "",
        "year": "2026",
        "coverUrl": null,
        "hasAttachment": true
      }
    ],
    "total": 1,
    "page": 1,
    "size": 20
  }
}
```

字段为空时返回空字符串或 `null`，不要用演示文本填充。

### 2.2 资料详情

```http
GET /api/school-materials/{id}
```

详情至少返回：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "id": 1,
    "resourceCode": "z2026-997c2338c9434",
    "title": "2024交附自招数学真题-含答案",
    "resourceCategory": "自招配套资料",
    "subjectCategory": "数学",
    "resourceType": "真题及答案",
    "summary": "",
    "content": "",
    "attachments": [
      {
        "id": 1,
        "name": "2024交附自招数学真题-含答案.pdf",
        "url": "https://example.com/file.pdf",
        "extension": "pdf",
        "mimeType": "application/pdf",
        "size": 123456,
        "sort": 1
      }
    ]
  }
}
```

若现有表中附件 URL、扩展名、文件名位于其他关联表，请在后端完成关联查询，不要求前端直接查询数据库。

## 3. 首页展示规则

首页点击“择校资料”后进入资料列表，不显示二维码弹窗。

列表卡片应优先展示：

1. `resourceCategory`；
2. `title`；
3. `subjectCategory`、`resourceType`；
4. 实际摘要或文件类型；
5. 实际发布日期（没有则不显示）。

详情页展示完整资料信息和附件。没有附件时返回空数组，前端显示“暂无附件”。

## 4. 下载要求

- 附件必须返回可访问的 HTTPS 持久地址；
- 文件类型至少支持 PDF、DOC、DOCX、XLS、XLSX；
- 前端使用 `wx.downloadFile` 和 `wx.openDocument`；
- 下载无需登录，除非后端明确改为鉴权下载并同步错误码；
- OSS 域名必须加入小程序 `downloadFile` 合法域名；
- 中文文件名 URL 必须可通过 `encodeURI` 正常下载。

## 5. 数据查询与排序

- 只返回有效、未删除、允许前端展示的资源；
- 默认按实际业务排序字段升序，再按 `id` 倒序；
- 不得硬编码或拼接“2026年上海中考到区分数线”等演示数据；
- `resource_code` 必须稳定且唯一；
- 列表分页必须稳定，不能因排序不固定导致重复或漏项。

## 6. 验收标准

- 首页进入“择校资料”后，首屏数据与 `zhongkao_resource_file` 实际记录一致；
- 至少能看到截图中 `自招配套资料`、`数学`、`真题及答案` 等真实字段；
- 详情页能打开对应真实资源；
- 至少一条真实附件可以下载并在微信中预览；
- 不再出现后端演示资料；
- 过滤、分页、详情、空附件和不存在 ID 均有测试结果；
- 提供实际接口响应样例和数据库查询验证结果。
