# 招生文章与“志愿填报小知识”后端接口实现交接文档

更新时间：2026-09-10  
交接对象：后端 Codex

## 一、当前问题

前端已在“中考查分工具”页面祝福墙下方接入两个模块：

1. 详细文章
2. 志愿填报小知识

目前模块没有文章数据，主要原因是前端请求的接口尚未提供可用数据，或文章表数据尚未同步到当前运行环境/云数据库。

前端不会把文章正文、文章标题或 OSS 地址写死在页面中，必须由后端接口返回正式数据。

## 二、必须提供的接口

### 1. 文章列表

```text
GET /api/admission-content/articles
```

请求参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `category` | 是 | `详细文章` 或 `志愿填报小知识` |
| `year` | 否 | 仅详细文章使用，例如 `2026` |

前端实际请求示例：

```text
GET /api/admission-content/articles?category=详细文章&year=2026
GET /api/admission-content/articles?category=志愿填报小知识
```

建议返回标准分页结构，前端同时兼容数组格式：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "records": [
      {
        "id": 19,
        "category": "志愿填报小知识",
        "title": "中考有哪些科目，分数如何分配",
        "year": null,
        "contentFormat": "text_with_images",
        "coverImageUrl": "https://lianpeng.oss-cn-shanghai.aliyuncs.com/admission-content/missing-subject-score/01.png",
        "imageCount": 1,
        "sortOrder": 1
      }
    ],
    "total": 11,
    "size": 11,
    "current": 1,
    "pages": 1
  }
}
```

列表接口只返回摘要字段，不返回长正文。

### 2. 文章详情

```text
GET /api/admission-content/articles/{id}
```

成功响应：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "id": 19,
    "category": "志愿填报小知识",
    "title": "中考有哪些科目，分数如何分配",
    "year": null,
    "contentFormat": "text_with_images",
    "contentText": "中考考试科目包括……\n\n各科分值如下：",
    "imageUrls": [
      "https://lianpeng.oss-cn-shanghai.aliyuncs.com/admission-content/missing-subject-score/01.png"
    ],
    "imageCount": 1
  }
}
```

接口字段必须使用 `imageUrls`，不要把数据库字段名 `oss_image_urls` 或采集字段 `image_urls` 原样返回给前端。

## 三、数据库映射要求

数据表：`admission_content_article`

| 数据库字段 | 接口字段 | 要求 |
|---|---|---|
| `id` | `id` | 详情查询主键 |
| `source_category` | `category` | 详细文章/志愿填报小知识 |
| `title` | `title` | 文章标题 |
| `article_year` | `year` | 详细文章年份，知识类返回 null |
| `content_format` | `contentFormat` | text/text_with_images |
| `content_text` | `contentText` | 纯文本正文 |
| `oss_image_urls` | `imageUrls` | JSON 数组，按正文顺序 |
| `image_count` | `imageCount` | 应等于 imageUrls.length |
| `sort_order` | `sortOrder` | 同栏目升序 |

以下字段不建议返回前端：`source_url`、`image_urls`、`local_image_files`、`capture_note`。

## 四、业务规则

### 详细文章

- 当前有效数据只有 2026 年 1 篇。
- 2024、2025 年旧详细文章不要返回。
- 当传入 `year=2026` 时，只返回 `article_year=2026` 的文章。
- 后续新增年份时，接口应根据数据库数据返回，不要在后端写死年份。

### 志愿填报小知识

- 当前有效数据 11 篇。
- `article_year` 为 `null`。
- 不按年份筛选。
- 按 `sort_order ASC, id ASC` 稳定排序。

### 数据完整性

- 当前应有文章总数：12 篇。
- 详细文章：1 篇。
- 志愿填报小知识：11 篇。
- 有配图文章：5 篇。
- 图片总数：14 张。
- 12 篇文章均应有完整 `content_text`。
- 没有配图时返回 `imageUrls: []`，不要返回 null。

## 五、错误响应

统一使用项目现有响应格式：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {}
}
```

文章不存在：

```json
{
  "code": 404,
  "msg": "文章不存在",
  "data": null
}
```

列表没有数据时仍返回业务码 200：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "records": [],
    "total": 0,
    "size": 0,
    "current": 1,
    "pages": 0
  }
}
```

接口不能把异常、数据库连接失败或空对象伪装成成功数据。

## 六、鉴权与部署

- 两个接口用于公开内容查询，建议加入 JWT 公开白名单。
- 如果项目公共接口默认不需要 JWT，则保持无需登录访问。
- 完成 Controller、Service、Mapper/Repository 后，必须重启 Spring Boot 服务。
- 如果使用云托管，必须重新部署后端服务。
- 必须将 `admission_content_article` 表及 12 篇数据增量同步到云数据库，禁止整库覆盖。

验收结果至少应满足：

7. OSS 图片地址 HTTP 状态为 200。
8. 未登录访问接口不会返回 401。
9. 云端接口与本地接口返回数量一致：12 篇、14 张图。
