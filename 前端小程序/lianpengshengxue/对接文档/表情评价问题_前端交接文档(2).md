# 学校介绍五级表情评价：前端交接文档

## 功能目标

在学校介绍页展示五个表情，用户点击后提交评价；每个登录用户对同一所学校最终只能保留一个评价；页面显示五个表情当前的选择人数。

后端已完成数据库表和接口，前端只需接入调用。

> **2026-09-09 必须同步的修复：**测试版如果只传 `schoolId`，会出现“有的能评价、有的提示学校不存在”，并可能把评价记到同数字 ID 的另一类学校。所有学校详情页必须同时传 `schoolSource`，不能依赖后端默认值。

## 鉴权

两个接口都需要登录。请求头携带：

```http
Authorization: Bearer <登录后获得的JWT>
```

未登录或 Token 失效时，接口返回 HTTP 401。前端应提示用户先登录，不要把接口错误显示成“暂无评价”。

## 获取评价数据

```http
GET /api/school-reactions/{schoolId}?schoolSource={schoolSource}
```

示例：

```http
GET /api/school-reactions/123?schoolSource=junior
Authorization: Bearer <token>
```

成功响应：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "reactionType": 2,
    "counts": {
      "1": 14,
      "2": 10,
      "3": 5,
      "4": 2,
      "5": 1
    }
  }
}
```

`reactionType` 是当前登录用户的选择，没有选择时为 `null`。`counts` 始终包含 1～5 五个键，没有人选择时对应值为 0。

## 提交或更换评价

```http
POST /api/school-reactions/{schoolId}
Content-Type: application/json
Authorization: Bearer <token>
```

请求体：

```json
{
  "reactionType": 1,
  "schoolSource": "junior"
}
```

`reactionType` 只能是 1、2、3、4、5。提交成功后，后端会返回更新后的完整数据，前端直接用返回值刷新五个计数和当前选中状态：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "reactionType": 1,
    "counts": { "1": 15, "2": 10, "3": 5, "4": 2, "5": 1 }
  }
}
```

## 页面交互建议

1. 进入学校介绍页后调用 GET，初始化五个表情的计数和当前用户选中状态。
2. 点击表情时先显示提交中状态，调用 POST。
3. POST 成功后使用响应中的 `data` 更新页面；再次点击其他表情即视为更换评价，旧表情人数会自动减 1，新表情人数自动加 1。
4. POST 失败时恢复点击前状态，并提示“评价提交失败，请重试”。
5. 同一页面只允许高亮 `reactionType` 对应的一个表情。

## 错误处理

- HTTP 401：要求用户登录或重新登录。
- `code` 非 200：提示接口返回的 `msg`。
- `reactionType` 不在 1～5：前端不要发起请求。
- `schoolSource` 只允许 `international`、`score`、`junior`、`general`。
- 学校不存在时接口返回错误，不要写入本地缓存。

## 重要说明

必须同时传学校详情接口返回的 `id` 和对应的 `schoolSource`，不要使用数组下标：

| 页面/数据接口 | schoolSource |
|---|---|
| `/api/schools/**` 国际学校 | `international` |
| `/api/score-query/schools/**` 分数查询高中 | `score` |
| `/api/junior-schools/**` 初中 | `junior` |
| `/api/general-high-schools/**` 一般高中 | `general` |

GET 请求把 `schoolSource` 放在查询参数中；POST 请求把它和 `reactionType` 一起放在 JSON 请求体中。旧的国际学校页面暂时可以省略，后端默认按 `international` 处理，但新代码建议全部明确传值。

## 可直接复制的前端调用

```js
async function loadSchoolReaction(schoolSource, schoolId) {
  return request(
    `/api/school-reactions/${Number(schoolId)}?schoolSource=${encodeURIComponent(schoolSource)}`,
    'GET',
    null,
    true
  )
}

async function submitSchoolReaction(schoolSource, schoolId, reactionType) {
  return request(
    `/api/school-reactions/${Number(schoolId)}`,
    'POST',
    {
      schoolSource,
      reactionType: Number(reactionType)
    },
    true
  )
}
```

页面不要自行猜来源，应在进入详情页时就确定并保存：

```js
// 国际学校详情
this.schoolSource = 'international'

// 分数查询高中详情
this.schoolSource = 'score'

// 初中详情
this.schoolSource = 'junior'

// 一般高中详情
this.schoolSource = 'general'
```

加载和点击时始终复用同一个来源：

```js
await loadSchoolReaction(this.schoolSource, this.data.school.id)
await submitSchoolReaction(this.schoolSource, this.data.school.id, reactionType)
```

验收时至少各选一所国际学校、分数查询高中、初中和一般高中。每一所都要验证：进入页面能加载五项计数、首次评价成功、更换评价成功、退出再进入仍高亮上次选择。Network 中 GET 查询参数和 POST 请求体里的 `schoolSource` 必须一致。
