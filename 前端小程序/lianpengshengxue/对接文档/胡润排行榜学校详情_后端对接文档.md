# 胡润排行榜学校详情：后端对接文档

## 1. 需求

首页“学校排行榜”进入排行榜页后，点击“胡润排行榜”中的学校名称，进入对应学校详情页。

详情页排版沿用现有体制外学校详情页（`pages/school-detail/school-detail`），必须按体制外学校口径展示，不得跳转到体制内学校详情页，也不得使用体制内学校接口。

当前排行榜页：`pages/school-ranking/index`。现有排行榜数据中的学校只有 `rank`、`name`、`city`，缺少可靠的学校主键，前端不能仅依赖学校名称模糊匹配。因此需要后端为每条榜单记录提供明确的体制外学校关联 ID。

## 2. 排行榜数据接口

现有静态榜单可继续作为展示数据，但后端应提供正式接口：

```http
GET /api/rankings/hurun?year=2025&page=1&size=100&city=上海市
```

响应：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "ranking": "hurun",
    "year": "2025",
    "title": "2025胡润百学·中国国际化学校排行榜",
    "subtitle": "Hurun Education Top International Schools in China 2025",
    "records": [
      {
        "rank": 1,
        "name": "上海民办包玉刚实验学校",
        "city": "上海市",
        "schoolId": 123,
        "schoolSource": "international"
      }
    ],
    "total": 1,
    "page": 1,
    "size": 100
  }
}
```

要求：

- `schoolId` 必须是学校库体制外学校的稳定 ID；
- `schoolSource` 固定返回 `international`；
- 不允许前端通过名称模糊搜索确定学校 ID；
- 若榜单学校暂未在学校库建立映射，`schoolId` 返回 `null`，前端该条不可点击并显示无详情提示；
- 榜单的排名、年份、学校名称和城市以数据库真实数据为准，不要由前端硬编码维护。

## 3. 学校详情接口

优先复用现有体制外详情接口：

```http
GET /api/schools/{schoolId}
```

如现有接口无法覆盖榜单学校，增加明确接口：

```http
GET /api/rankings/hurun/schools/{schoolId}
```

但无论使用哪个接口，返回数据必须为体制外学校详情，并保证 `schoolSource=international`。

详情至少需要支持现有体制外详情页使用的字段：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "id": 123,
    "schoolSource": "international",
    "name": "上海民办包玉刚实验学校",
    "shortName": "包玉刚",
    "district": "上海市",
    "schoolType": "民办",
    "grades": "小学、初中、高中",
    "logoUrl": "https://.../logo.jpg",
    "backgroundImageUrl": "https://.../background.jpg",
    "curriculum": "IB / A-Level",
    "tuitionMin": 10,
    "tuitionMax": 20,
    "boardingInfo": "",
    "schoolIntro": "学校介绍",
    "featureTags": [],
    "contact": {},
    "admissionContent": []
  }
}
```

具体字段以现有体制外详情接口实际返回为准，但不能返回体制内专用字段口径替代体制外详情数据。

## 4. 前端跳转约定

排行榜记录点击后，前端使用：

```text
/pages/school-detail/school-detail?id={schoolId}&schoolSource=international
```

后端必须保证：

- `schoolId` 对应体制外学校；
- `schoolSource=international` 时不会返回体制内学校；
- 无效 ID 返回统一 404 业务响应；
- 学校已下架或不存在时，详情页能显示明确错误。

## 5. 数据库与映射要求

请在榜单表或映射表中保存排行榜记录与学校库学校的关系，至少包含：

- `ranking_type`：`hurun`；
- `ranking_year`：如 `2025`；
- `rank`；
- `school_id`：体制外学校 ID；
- `school_source`：固定 `international`；
- `school_name_snapshot`：榜单展示名称；
- `city`；
- `status` / 软删除字段。

不要使用学校名称作为唯一关联键。学校更名、校区名称变化或同名学校必须仍能定位到正确学校。

## 6. 验收标准

- 胡润榜每条有映射的学校名称可点击；
- 点击后进入体制外学校详情页；
- 详情页显示学校 logo、学校性质、课程体系、学段、学费、介绍等体制外信息；
- 不会跳转到体制内详情页；
- 上海民办包玉刚实验学校等真实榜单记录可完成端到端测试；
- 未映射学校不会错误跳转到同名学校；
- 不存在或下架学校返回 404，并由前端提示“学校详情暂不可用”；
- 城市筛选、排行榜切换不影响学校 ID 映射；
- 提供接口响应、数据库映射和端到端测试结果。
