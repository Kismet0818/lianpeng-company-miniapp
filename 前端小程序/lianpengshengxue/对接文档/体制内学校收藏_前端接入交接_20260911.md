# 体制内学校收藏前端接入交接（2026-09-11）

## 结论

后端收藏已支持五类学校来源。前端必须把 `schoolSource` 和 `schoolId` 一起提交，并在收藏列表跳转详情时继续携带这两个字段。

| 学校类型 | `schoolSource` |
|---|---|
| 国际学校 | `international` |
| 分数查询高中 | `score` |
| 初中 | `junior` |
| 一般高中 | `general` |
| 小学 | `primary` |

学校 ID 只在各自表中唯一，因此不得只按 `schoolId` 判断是否收藏。

## 收藏/取消收藏

```http
POST /api/favorite/toggle
Authorization: Bearer <JWT>
Content-Type: application/json
```

```json
{
  "schoolSource": "junior",
  "schoolId": 1
}
```

后端暂时兼容旧国际学校请求 `{ "school_id": 1 }`，但体制内学校必须使用新格式。

前端收藏状态、本地缓存键、去重逻辑都必须使用复合键：

```js
const favoriteKey = `${schoolSource}:${schoolId}`
```

## 收藏列表

```http
GET /api/favorite/list
Authorization: Bearer <JWT>
```

每项新增返回 `schoolSource`。从收藏列表打开详情时，必须按来源选择页面并同时传递来源与 ID：

```js
const pageBySource = {
  international: '/pages/school-detail/school-detail',
  score: '/pages/score-school-detail/score-school-detail',
  junior: '/pages/junior-school-detail/junior-school-detail',
  general: '/pages/general-high-school-detail/general-high-school-detail',
  primary: '/pages/primary-school-detail/primary-school-detail'
}

const page = pageBySource[item.schoolSource]
wx.navigateTo({
  url: `${page}?id=${item.schoolId}&schoolSource=${encodeURIComponent(item.schoolSource)}`
})
```

页面路径以正式前端当前 `app.json` 为准，不要直接照抄不存在的示例路径。

## 真机验收

1. 分别收藏一所国际学校、一所初中、一所一般高中和一所分数高中。
2. 进入“我的收藏”，确认四所学校都显示且名称不串校。
3. 从收藏列表逐项进入详情，确认进入对应来源的正确学校。
4. 再次点击收藏按钮，确认只取消当前“来源 + ID”的学校，不影响相同数字 ID 的另一来源学校。
5. 退出后重新进入小程序，确认收藏状态仍正确。
