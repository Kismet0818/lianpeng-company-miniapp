> 完成日期：2026-09-16  
> 当前范围：后端代码、本地数据库、真实 HTTP 与 OSS 文件验收已完成；未迁移云数据库、未部署云托管。正式前端源码不在本机，因此本文给出可直接接入的接口和页面改造要求，不把旧前端副本当成已完成。

## 1. 实际接口

### 1.1 资料列表（公开、无需登录）

```http
GET /api/school-materials?page=1&size=20&category=政策资料&keyword=分数线&schoolLevel=高中&year=2026
```

参数均可选；`page` 最小为 1，`size` 限制为 1—50。列表只返回 `status=1` 且未软删除的资料，顺序为 `sort ASC, publishDate DESC, id DESC`。

### 1.3 管理接口（需要 `X-Admin-Key`）

| 方法 | 路径 | 用途 |
|---|---|---|
| `POST` | `/api/admin/school-materials` | 新增资料，返回新 ID |
| `PUT` | `/api/admin/school-materials/{id}` | 完整更新资料 |
| `PATCH` | `/api/admin/school-materials/{id}/status?status=0或1` | 下架/上架 |
| `DELETE` | `/api/admin/school-materials/{id}` | 软删除资料及其附件记录 |
| `POST` | `/api/admin/school-materials/{id}/attachments` | `multipart/form-data` 上传附件，可带 `sort` |
| `DELETE` | `/api/admin/school-materials/{id}/attachments/{attachmentId}` | 软删除附件记录 |

## 2. 数据库

建表脚本：`tools/create_school_material.sql`。  
可重复执行的本地测试数据：`tools/seed_school_material_demo.sql`。

### `school_material`

资料主表，保存稳定业务编号、标题、分类、学段、年份、摘要、正文、封面、发布日期、排序、上下架和软删除状态。`material_code` 唯一；公开接口使用数据库 `id`。

### `school_material_attachment`

附件表，保存资料 ID、显示文件名、持久 URL、扩展名、MIME、文件字节数、排序、启用和软删除状态。外键关联资料主表。

## 3. 文件存储与限制

- 管理接口上传新附件时调用现有 OSS 服务，目录为 `school-materials/{materialId}/`。
- 公开详情直接返回持久 HTTPS URL，不使用临时本地路径，也不要求用户登录。
- 允许扩展名：`pdf`、`doc`、`docx`、`xls`、`xlsx`。
- 单文件最大 20MB；空文件、无扩展名或其他类型返回业务码 400。
- 测试资料复用项目自有 OSS 的已有 PDF，没有重复上传。
- 实测测试 PDF：HTTP 200、`Content-Type: application/pdf`、大小 2,686,158 字节。
- 小程序后台需将 `https://lianpeng.oss-cn-shanghai.aliyuncs.com` 配置为 `downloadFile` 合法域名。若已有相同 OSS 域名无需重复添加。
- 小程序原生请求不受浏览器 CORS 影响；若未来 H5 调用 OSS，需要另行配置 Bucket CORS。

2. 首页 `pages/home/home.js` 的 `onMaterials` 改为：


3. 列表页调用 `GET /api/school-materials`，使用 `id` 跳转详情。
4. 详情页调用 `GET /api/school-materials/{id}`；`attachments` 为空时显示“暂无附件”。

### 4.2 下载并打开附件

```js
openAttachment(e) {
  const item = e.currentTarget.dataset.item
  if (!item || !item.url) {
    wx.showToast({ title: '附件地址无效', icon: 'none' })
    return
  }
  wx.showLoading({ title: '下载中' })
  wx.downloadFile({
    url: encodeURI(item.url),
    success: ({ statusCode, tempFilePath }) => {
      if (statusCode !== 200) {
        wx.showToast({ title: '附件下载失败', icon: 'none' })
        return
      }
      wx.openDocument({
        filePath: tempFilePath,
        fileType: item.extension,
        showMenu: true,
        fail: () => wx.showToast({ title: '文件打开失败', icon: 'none' })
      })
    },
    fail: () => wx.showToast({ title: '附件下载失败', icon: 'none' }),
    complete: () => wx.hideLoading()
  })
}
```

中文文件名 URL 建议调用 `encodeURI`，不要对完整 URL 使用 `encodeURIComponent`。

## 5. 错误与规则

| 情况 | 业务码 | 提示 |
|---|---:|---|
| 资料不存在/下架/删除 | 404 | 资料不存在或已下架 |
| 管理密钥缺失或错误 | 401 | 管理权限验证失败 |
| 标题/分类/学段缺失 | 400 | 对应参数不能为空 |
| 非法上下架值 | 400 | status 只能为0或1 |
| 附件不存在 | 404 | 附件不存在 |
| 附件过大 | 400 | 附件不能超过20MB |
| 附件格式错误 | 400 | 仅支持PDF、DOC、DOCX、XLS、XLSX |

删除采用软删除。资料下架或删除后立即从列表消失，详情返回业务码 404；附件 URL 本身不会在软删除时从 OSS 物理删除，避免误删共享文件，若确认文件不再复用再由管理员单独清理 OSS。

## 8. 与需求文档的差异

- 示例建议字符串 ID，实际沿用项目数据库风格返回 `Long` ID；前端作为普通值透传即可。
- 响应成功文案沿用项目标准 `成功`，不是英文 `success`。
- 当前文件采用公开持久 OSS URL，所以下载无需 JWT，也没有新增后端文件中转接口。
- 管理能力通过受保护的 API 实现，尚未给 `admin.html` 增加可视化资料管理页。
- 正式前端不在本机，本次不修改旧副本；前端按本文在最后实际发布源码中接入。
