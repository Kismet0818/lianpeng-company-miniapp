# 择校资料下载功能：前后端对接文档

## 1. 需求背景

首页“择校资料”目前仅有弹窗提示，需改为真实的资料列表与下载/打开功能。

交互形态参考首页“升学规划”进入“升学路径 / 规划须知”后的资料详情页：

- 展示资料分类、标题、摘要、发布时间；
- 详情页展示正文或资料说明；
- 展示“政策附件/资料附件”按钮；
- 点击附件后由微信小程序下载并打开文件，而不是只显示弹窗；
- 支持 PDF、DOC、DOCX、XLS、XLSX 等常见资料格式。

前端当前相关实现可参考：

- 首页入口：`pages/home/home.js` 的 `onMaterials`；
- 首页入口模板：`pages/home/home.wxml` 的“择校资料”；
- 升学规划列表：`pages/guide-list/`；
- 文章详情及附件下载：`pages/guide-detail/guide-detail.js` 的 `openPolicyAttachment`。

## 2. 后端需要提供的接口

### 2.1 资料列表

```http
GET /api/school-materials
```

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| page | integer | 否 | 页码，默认 1 |
| size | integer | 否 | 每页数量，默认 20，最大 50 |
| category | string | 否 | 资料分类，如 `升学路径`、`规划须知`、`政策资料` |
| keyword | string | 否 | 标题关键词 |
| schoolLevel | string | 否 | `幼儿园`、`小学`、`初中`、`高中`、`通用` |
| year | string | 否 | 学年或年份 |

建议响应：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "records": [
      {
        "id": "material-001",
        "title": "2026上海市高中自主招生学校名单",
        "category": "政策资料",
        "schoolLevel": "高中",
        "summary": "2026上海市高中自主招生学校名单",
        "publishDate": "2026-06-17",
        "coverUrl": "https://.../cover.png",
        "hasAttachment": true,
        "sort": 1
      }
    ],
    "total": 1,
    "page": 1,
    "size": 20
  }
}
```

### 2.2 资料详情

```http
GET /api/school-materials/{id}
```

建议响应：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": "material-001",
    "title": "2026上海市高中自主招生学校名单",
    "category": "升学路径",
    "schoolLevel": "高中",
    "summary": "2026上海市高中自主招生学校名单",
    "publishDate": "2026-06-17",
    "content": "资料说明正文，可为空",
    "attachments": [
      {
        "id": "attachment-001",
        "name": "2026上海市高中自主招生学校名单.pdf",
        "url": "https://.../materials/2026-high-school-list.pdf",
        "extension": "pdf",
        "mimeType": "application/pdf",
        "size": 1234567,
        "sort": 1
      }
    ]
  }
}
```

## 3. 文件地址与下载要求

1. `url` 必须是前端可访问的 HTTPS 持久地址，不能返回临时本地路径。
2. 文件服务器须允许微信小程序合法域名访问，并正确返回 `200`、`Content-Type` 和文件内容。
3. 如采用鉴权下载，请提供以下任一种方案：
   - 返回带有效期的 HTTPS 签名 URL；
   - 或提供 `GET /api/school-materials/{id}/attachments/{attachmentId}/download`，前端携带登录 token 下载。
4. 附件下载接口不能依赖微信登录 code；若需要用户身份，使用现有 token 机制。
5. 后端应限制附件类型和大小，并在资料下架时返回明确错误信息。

## 4. 前端预期交互

首页点击“择校资料”后进入资料列表页，不再使用原弹窗。

资料详情页点击附件时，前端使用：

```js
wx.downloadFile({ url })
wx.openDocument({ filePath, fileType: extension, showMenu: true })
```

前端需处理：加载中、下载失败、文件打开失败、资料不存在、附件地址无效等状态。

## 5. 数据和后台管理要求

后端应支持资料的新增、编辑、上下架、分类、排序、发布时间和附件管理。列表默认只返回已上架资料。

请明确以下规则：

- `id` 在资料生命周期内保持稳定；
- `sort` 越小越靠前；
- `publishDate` 使用 `YYYY-MM-DD`；
- `attachments` 为空时前端展示“暂无附件”，不能伪造下载按钮；
- 删除或下架资料后，详情接口返回业务错误，不返回旧缓存内容；
- 列表和详情均使用项目现有标准响应格式。

## 6. 验收标准

- 首页“择校资料”可进入真实资料列表；
- 至少存在一条可测试的 PDF 资料；
- 列表字段与详情字段完整返回；
- 点击附件可下载并用微信文档预览打开；
- 下载失败时前端有明确提示；
- 资料下架后列表不再展示，详情访问得到明确错误；
- 未登录用户是否允许下载必须由后端明确说明；若需要登录，需返回统一的认证错误码；
- 分类筛选、分页和排序行为可被前端稳定调用。
