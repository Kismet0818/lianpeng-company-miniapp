# 查分工具学校名额与志愿查询：前端对接文档（2026-09-14）

## 一、交付状态

- 后端已完成并在本地 `http://127.0.0.1:18080` 使用真实 MySQL 数据验收。
- 所有接口均为公开查询接口，不需要 JWT，也不要附带管理员密钥。
- 默认学年为 `2025-2026`；当前数据库也只有该学年。
- 本次尚未部署微信云托管。前端正式环境调用前，必须等待后端新版本发布；本机旧前端不是正式修改目标。

## 二、前端必须遵守的页面流程

1. 用户选择 `初中` 或 `高中`，输入学校名后调用统一搜索接口。
2. 学校身份始终保存为 `schoolSource + id`，不能只保存数字 ID。
3. 高中搜索结果固定为 `level=high, schoolSource=score`：
   - 详情：`GET /api/score-query/schools/{id}`；
   - 名额到区：`GET /api/score-query/region?year=2025-2026&highSchoolId={id}`；
   - 名额到校：`GET /api/score-query/school?year=2025-2026&highSchoolId={id}`；
   - 1–15 志愿：`GET /api/score-query/volunteer?year=2025-2026&highSchoolId={id}`。
4. 初中搜索结果固定为 `level=junior, schoolSource=junior`：
   - 详情：`GET /api/junior-schools/{id}`；
   - 只调用名额到校：`GET /api/score-query/school?year=2025-2026&district={district}&school={name}`；
   - 不得调用或展示名额到区、1–15 志愿。

## 三、统一学校搜索

```http
GET /api/score-query/schools/search?level=junior|high&name={关键词}&page=1&size=20
```

参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `level` | 是 | 正式使用 `junior` 或 `high`；后端兼容 `senior`，但新前端统一传 `high` |
| `name` | 是 | 去除首尾空格后匹配全名、简称或名称片段；最长 100 字符 |
| `page` | 否 | 默认 1，范围 1–200 |
| `size` | 否 | 默认 20，范围 1–100 |

真实请求：

```http
GET /api/score-query/schools/search?level=high&name=上海中学&page=1&size=20
```

真实响应（HTTP 200）：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "records": [
      {
        "id": 50,
        "name": "上海中学东校",
        "shortName": null,
        "district": "浦东新区",
        "level": "high",
        "schoolSource": "score"
      },
      {
        "id": 10,
        "name": "上海市上海中学",
        "shortName": null,
        "district": "徐汇区",
        "level": "high",
        "schoolSource": "score"
      }

```

无结果不是错误，返回 HTTP 200、`code=200`、`records=[]`、`total=0`。

## 六、初中名额到校

必须同时传搜索结果中的 `district` 和 `name`：

```http
GET /api/score-query/school?year=2025-2026&district=徐汇区&school=上海市南洋模范初级中学
```

真实响应中的一条记录：

```json
{
  "id": 1294,
  "highSchoolId": 10,
  "highSchoolName": "上海市上海中学",
  "highSchoolDistrict": "徐汇区",
  "targetType": 1,
  "targetDistrict": "徐汇区",
  "targetSchoolName": "上海市南洋模范初级中学",
  "quotaCount": 2,
  "minScore": 716,
  "changeRange": null,
  "academicYear": "2025-2026"
}
```

注意：这里的 `highSchoolId/highSchoolName` 是向该初中投放名额的高中；当前初中的身份仍然是搜索结果返回的 `schoolSource=junior + id`。

## 七、字段与空态规则

- `quotaCount`：名额数量，数字。
- `planCount`：1–15 志愿计划数，数字。
- `minScore`：最低分，未公布时为 `null`，不得用空字符串参与计算。
- `changeRange`：正数上升、负数下降、0 持平、`null` 表示无可比数据。
- `targetDistrict`：名额或志愿投放地区。
- `targetSchoolName`：名额到校对应的初中名称。
- 所有成功空结果都使用空数组，前端展示“暂无该校该年度数据”，不能当成网络错误。
- `year` 不传时默认 `2025-2026`；格式错误或数据库没有该年份时返回 HTTP 400。

年份错误响应：

```json
{"code":400,"msg":"年份格式错误或暂无该年份数据","data":null}
```
